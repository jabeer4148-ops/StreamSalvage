## StreamSalvage v1.0.1

Repair corrupted OBS MP4 recordings caused by crashes — locally, on your Windows PC.

### What's new in 1.0.1
- The free preview is now a true 30-second clip. The full repaired recording is written only when you export with a license.
- New app icon and installer branding.

### What it does
- Repairs MP4 / MOV / M4V files missing their MOOV atom (OBS crash, power loss, stopped recording)
- Drag and drop — no command line needed
- 100% local processing — your files never leave your PC
- Free 30-second preview before you pay
- $29 one-time license to export the full repaired file; full refund if it doesn't work

### How to install
1. Download `StreamSalvage_1.0.1_x64-setup.exe`
2. Run the installer (you may see a SmartScreen prompt — click **More info → Run anyway**)
3. Open StreamSalvage and drag in your corrupted MP4

### System requirements
- Windows 10 or later (64-bit)
- 4 GB RAM minimum
